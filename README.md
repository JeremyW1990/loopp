# Loopp — AI Refund Support Agent

An AI customer support agent that processes or denies e-commerce refunds against a strict refund policy — with a customer chat UI and an admin dashboard exposing the agent's full reasoning trace (tool I/O, retries, token cost, latency).

**Stack:** TypeScript end-to-end — React (Vite) · tRPC · Express · Drizzle ORM · PostgreSQL · Anthropic Claude (raw tool calling)

🚧 Work in progress — setup instructions land with the first working slice.
